## 目标结构与迁移边界

```text
题目、原件、用户补充
  → 任务状态与有界 Harness ↔ 模型 API
       → 数据检查 / 已有算子 / ModelIR 编译求解 / 隔离代码实验
       ← 真实观察：数据摘要、数值、异常、指标、工件引用
       → 申请提交候选结果
  → 来源、数学与数值验收
       → 缺证据或失败：具体义务返回 Harness，预算不足则明确终止
       → 达到声明范围的验收：结果登记 → 写作、图表、导出
```

| 边界 | 唯一责任 |
| --- | --- |
| 模型 API 接入 | 现有供应商调用、工具消息与用量；不拥有验收状态或运行权限 |
| Harness | 下一行动调度、工具请求、观察、任务总预算、停止/取消、恢复与待解决义务；首轮单控制循环 |
| 工具注册与执行 | 同一合同描述并校验输入/输出/参数、适用条件及能力限制；只发布确已实现的能力 |
| 隔离环境 | 强制文件/网络/资源权限，固化依赖，回收进程并记录退出状态；提示词限制不代替隔离 |
| 证据内核 | 绑定原件、数据变换、代码或 ModelIR、运行、验证与依赖版本；拥有正式结果登记和失效规则 |
| 写作与导出 | 消费正式结果及披露的局限，不从未验收实验取数充当结论 |

## 探索、来源与正式结果的约束

1. **探索可以先行，事实不能伪造。** 原件只读；观测数据、程序推导量、符号未知量、假设情景分别标识。表头、区域、类型、排序、清洗需记录变换与来源；不能把第二行表头当数据，也不能给符号 M 偷填数值。
2. **探索状态不授予正式许可。** 不依赖争议的读表/统计可以先做；涉及争议的试算只属于带假设与影响范围的候选情景。来源未评估/拒绝、过期证据和失败依赖不得支撑正式结论，独立分支按实际依赖保留。代码路径不能逃避 ModelIR 路径的来源义务。
3. **计算方式共享证据，不强求同一种表示。** ModelIR 保留类型化绑定、确定性构造与求解器校验；代码实验记录输入摘要、变换/代码哈希、环境/依赖、随机种子（适用时）、运行参数、输出和错误。把脚本路径包装成 ModelIR 不代表数学约束已验证。
4. **最小持久状态面向任务。** 保存子目标/义务、候选方案、行动与观察、工件引用、预算账本；上下文压缩不能丢失这些事实。大输出保存工件，模型读取有界摘要并可按需查看；首轮不建设独立长期记忆系统。
5. **恢复不重置预算或重放未知副作用。** 启动前登记动作身份与输入版本；完成、失败、在途未知分别记账。中断后的结果重验，未知动作先核对输出再决定重试；模型/数据/代码/来源改变使相关下游证据失效。
6. **完成声明只是验收申请。** Harness/验证器核对预先登记的题目义务与检查证据，模型不能修改验收标准、伪写等级，或以“无工具调用”表示数学完成。失败可返回具体义务进行有界修订，不能改名重试绕过限制。
7. **独立性依赖证据方法。** 自生成测试或第二次模型赞同不能单独成为数学证明；采用适用的独立重算、穷举、残差、守恒/边界、简单基线、时间切分/样本外验证与敏感性检查。缺适用证据则保留未验证。
8. **隔离必须实测。** 代码只访问任务获准文件与预装依赖，不继承密钥、宿主配置或仓库写权限；首轮计算环境禁外网，模型请求由宿主受控 API 层完成。路径越界、符号链接/目录联接、超时、取消、子进程与输出容量需实际探针；隔离不可用时拒绝执行，不回退到普通宿主解释器。
9. **固定任务总预算。** 首轮每题/每对照臂最多 24 次实际模型请求、1800 秒，包含审核、恢复和失败；同一合同最多两次实际尝试。token、工具次数、单次时间、CPU/内存和输出上限在 H1.1 按环境冻结、调用前核验，不留无限默认值。可以探索新方案，不能因换阶段/候选名/恢复会话清空总账；未知用量不计零，reasoning 不重复累计。
10. **状态分层。** 执行成功、来源支持、数学充分性、数值验证分别报告；部分、条件与完整结果区别呈现。被拒绝实验不进入正式结果/图表，失败诊断文档的审核 PASS 不算解题成功。
